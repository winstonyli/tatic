entry: what, why parked, trigger to reopen, evidence (verified 2026-10-17), status. The findings themselves stay in
`docs/tier-cycle.md`; this file points into it. Add an item the moment it is parked; delete it when it is built or
fixed, and say so in the doc. Milestones are in `ROADMAP.md`.

Status words: `parked` (deferred; the note says whether it was ever built or tried), `held for <check>` (waits on a named
run or decision), `decided against` (measured and rejected; kept short so it is not retried). Line numbers are for
`docs/tier-cycle.md` unless another file is named.
