# `runs` Tool Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (this plan's tasks build on each other's interfaces, so it runs inline) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One Rust tool, `tools/runs`, replaces the gate, timing and machine-state scripts (bash, PowerShell, Python, C#), and church_bv reads machine state natively instead of through a 5 s PowerShell.

**Architecture:** A separate crate (`tools/runs`, own `Cargo.lock` and `target`) with modules `state` (machine state, std-only, also compiled into church_bv by `#[path]`), `job` (one measured run in a job object), `cmp` (the gate comparison), `gate`, `time` (alternating rounds) and `main` (CLI, run directory). Every measured run starts suspended, joins a job object, then resumes.

**Tech Stack:** Rust 2024 (nightly 1.100 is the machine default), `windows-sys` 0.61 (job objects, Toolhelp, threading, `GetLongPathNameW`), `regex` 1.

**Spec:** `docs/superpowers/specs/2026-10-17-runs-tool-design.md` (local, gitignored). Read it before Task 1.

## Global Constraints

- Windows only: `compile_error!` off Windows in `tools/runs`; church_bv keeps "machine state unavailable" off Windows.
- `tools/runs/src/state.rs` depends on nothing but std (church_bv compiles it). Nothing is added to the root `Cargo.toml` or `Cargo.lock`.
- `tools/runs` is not a workspace member; build it with `--manifest-path tools/runs/Cargo.toml`; its target is `tools/runs/target`.
- Defaults: priority BelowNormal, affinity `0xFFF`, straggler wait 60 s, others `selfplay*`,`League*`, `--max-hours 3`, `--foreign-max 20`, `--quiet-secs 60`, `--max-rounds` 4N, `--sweep` rounds 6.

  - Timed one-offs (Task 8): run the GPU/CPU checks from LONG_RUNS.md first. Report `(Get-MpComputerStatus).RealTimeProtectionEnabled` (or `runs state`) and `\Processor(_Total)` load with every timing. Never change Defender or system settings.

```rust
//! Machine state for timings (LONG_RUNS.md): the machine's CPU load from `GetSystemTimes`, whether this process holds the
//! "Lock pages in memory" privilege, and Defender's real-time protection.
//! church_bv compiles this same file (`tests/church_bv/machine.rs`, `#[path]`), so it must depend on nothing but std:
//! its Win32 calls are declared here, as `driver.rs`'s `stdio` declares its own.
#![allow(dead_code)] // each of the two crates uses part of it

use std::ffi::c_void;
use std::process::{Command, Stdio};
use std::time::Duration;

#[repr(C)]
#[derive(Default, Clone, Copy)]
struct FileTime {
    low: u32,
    high: u32,
}

impl FileTime {
    fn get(self) -> u64 {
        (self.high as u64) << 32 | self.low as u64
    }
}

/// A privilege's locally unique id.
#[repr(C)]
#[derive(Default, Clone, Copy, PartialEq, Debug)]
pub struct Luid {
    pub low: u32,
    pub high: i32,
}

#[link(name = "kernel32")]
unsafe extern "system" {
    fn GetSystemTimes(idle: *mut FileTime, kernel: *mut FileTime, user: *mut FileTime) -> i32;
    fn GetCurrentProcess() -> *mut c_void;
    fn CloseHandle(handle: *mut c_void) -> i32;
    fn LoadLibraryW(name: *const u16) -> *mut c_void;
    fn GetProcAddress(module: *mut c_void, name: *const u8) -> *mut c_void;
    fn FreeLibrary(module: *mut c_void) -> i32;
}

#[link(name = "advapi32")]
unsafe extern "system" {
    fn OpenProcessToken(process: *mut c_void, access: u32, token: *mut *mut c_void) -> i32;
    fn GetTokenInformation(token: *mut c_void, class: u32, info: *mut c_void, len: u32, returned: *mut u32) -> i32;
    fn LookupPrivilegeValueW(system: *const u16, name: *const u16, luid: *mut Luid) -> i32;
}

const TOKEN_QUERY: u32 = 8;
const TOKEN_PRIVILEGES: u32 = 3;

/// The machine's processor times since boot, summed over all logical processors, in 100 ns units. Kernel time
/// includes idle time.
#[derive(Clone, Copy, Debug)]
pub struct Times {
    pub idle: u64,
    pub kernel: u64,
    pub user: u64,
}

pub fn times() -> Times {
    let (mut idle, mut kernel, mut user) = (FileTime::default(), FileTime::default(), FileTime::default());
    unsafe { GetSystemTimes(&mut idle, &mut kernel, &mut user) };
    Times { idle: idle.get(), kernel: kernel.get(), user: user.get() }
}

impl Times {
    /// Busy processor seconds (kernel + user - idle) and total processor seconds (wall × logical processors) from
    /// `earlier` to `self`.
    pub fn since(&self, earlier: &Times) -> (f64, f64) {
        let total = (self.kernel + self.user).saturating_sub(earlier.kernel + earlier.user);
        let idle = self.idle.saturating_sub(earlier.idle);
        (total.saturating_sub(idle) as f64 / 1e7, total as f64 / 1e7)
    }

    /// The machine's busy percentage from `earlier` to `self`, with no wait.
    pub fn load_since(&self, earlier: &Times) -> f64 {
        let (busy, total) = self.since(earlier);
        if total > 0.0 { 100.0 * busy / total } else { 0.0 }
    }
}

/// The machine's busy percentage over `window`, waited out here.
pub fn cpu_load(window: Duration) -> f64 {
    let a = times();
    std::thread::sleep(window);
    times().load_since(&a)
}

/// Whether a `TOKEN_PRIVILEGES` buffer (a count, then (LUID low, LUID high, attributes) triples of u32) lists `luid`.
pub fn privileges_contain(buf: &[u32], luid: Luid) -> bool {
    let n = buf.first().copied().unwrap_or(0) as usize;
    (0..n).any(|i| buf.get(1 + 3 * i) == Some(&luid.low) && buf.get(2 + 3 * i) == Some(&(luid.high as u32)))
}

/// Whether this process's token holds `SeLockMemoryPrivilege`, enabled or not: what `whoami /priv` listing it meant.
pub fn lockpriv() -> bool {
    let name: Vec<u16> = "SeLockMemoryPrivilege\0".encode_utf16().collect();
    let mut luid = Luid::default();
    if unsafe { LookupPrivilegeValueW(std::ptr::null(), name.as_ptr(), &mut luid) } == 0 {
        return false;
    }
    let mut token = std::ptr::null_mut();
    if unsafe { OpenProcessToken(GetCurrentProcess(), TOKEN_QUERY, &mut token) } == 0 {
        return false;
    }
    let mut buf = vec![0u32; 1024];
    let mut len = 0;
    let ok = unsafe { GetTokenInformation(token, TOKEN_PRIVILEGES, buf.as_mut_ptr().cast(), (buf.len() * 4) as u32, &mut len) };
    unsafe { CloseHandle(token) };
    ok != 0 && privileges_contain(&buf, luid)
}

/// What Defender's `ProductStatus` settles: bit 0, `MP_STATUS_FLAG_SERVICE_UNAVAILABLE`, means the service is not
/// running, so nothing protects in real time. Anything else is left to `Get-MpComputerStatus`.
pub fn rtp_from_status(product_status: u32) -> Option<bool> {
    (product_status & 1 != 0).then_some(false)
}

/// Defender's real-time protection: MpClient.dll's status (milliseconds) when it settles it, else one PowerShell
/// (about 1 s); `None` if both fail.
pub fn rtp() -> Option<bool> {
    mpclient_status().and_then(rtp_from_status).or_else(rtp_powershell)
}

/// `ProductStatus`, the first field `MpManagerStatusQueryEx` writes (probed on this machine, docs/tier-cycle.md,
/// "Survey: workflow time outside the sweep").
fn mpclient_status() -> Option<u32> {
    let dir = std::env::var("ProgramFiles").ok()?;
    let path: Vec<u16> = format!("{dir}\\Windows Defender\\MpClient.dll\0").encode_utf16().collect();
    type Open = unsafe extern "system" fn(u32, *mut *mut c_void) -> i32;
    type Query = unsafe extern "system" fn(*mut c_void, u32, *mut c_void) -> i32;
    type Close = unsafe extern "system" fn(*mut c_void) -> i32;
    unsafe {
        let module = LoadLibraryW(path.as_ptr());
        if module.is_null() {
            return None;
        }
        let open = GetProcAddress(module, b"MpManagerOpen\0".as_ptr());
        let query = GetProcAddress(module, b"MpManagerStatusQueryEx\0".as_ptr());
        let close = GetProcAddress(module, b"MpHandleClose\0".as_ptr());
        let mut status = None;
        if !open.is_null() && !query.is_null() && !close.is_null() {
            let (open, query, close): (Open, Query, Close) = (std::mem::transmute(open), std::mem::transmute(query), std::mem::transmute(close));
            let mut handle = std::ptr::null_mut();
            if open(0, &mut handle) >= 0 {
                let mut info = vec![0u32; 2048]; // 8 KB, zeroed: the status structure is smaller
                if query(handle, 0, info.as_mut_ptr().cast()) >= 0 {
                    status = Some(info[0]);
                }
                close(handle);
            }
        }
        FreeLibrary(module);
        status
    }
}

fn rtp_powershell() -> Option<bool> {
    let o = Command::new("powershell")
        .args(["-NoProfile", "-Command", "(Get-MpComputerStatus).RealTimeProtectionEnabled"])
        .stdin(Stdio::null())
        .output()
        .ok()?;
    match String::from_utf8_lossy(&o.stdout).trim() {
        "True" => Some(true),
        "False" => Some(false),
        _ => None,
    }
}

pub fn rtp_text(r: Option<bool>) -> &'static str {
    match r {
        Some(true) => "True",
        Some(false) => "False",
        None => "?",
    }
}

/// `RTP=False CPU=18%`: the machine-wide part of the state, which any process can read. CPU is the load over a 2 s
/// window, the window `Get-Counter` sampled before.
pub fn rtp_cpu() -> String {
    format!("RTP={} CPU={:.0}%", rtp_text(rtp()), cpu_load(Duration::from_secs(2)))
}

/// `RTP=False CPU=18% lockpriv=True`.
pub fn line() -> String {
    format!("{} lockpriv={}", rtp_cpu(), if lockpriv() { "True" } else { "False" })
}
```

```rust
/// machine-wide, so read here; `lockpriv` and `pages` belong to the children's process and environment, so a worker
/// task (`machine::pages_line`, with the children's `env`) reports them. `MACHINE_STATE=0` skips it, in a loop or a sweep.
fn machine_state(when: &str, env: &[(String, String)], worker: &Worker, out: &Path) {
    if env_or("MACHINE_STATE", 1usize) == 0 {
        return;
    }
    std::fs::create_dir_all(out).unwrap();
    let log = out.join(format!("machine_state_{when}.log"));
```

```rust
//! One measured run (`run`). The exe starts suspended, joins a new job object, then resumes, so every process it starts
//! is in the job with no race (`pin.ps1` assigned after the start, and `sweep_job.ps1` put its own PowerShell in the
//! job). The job sets priority, affinity and kill-on-close for all of them, and its accounting gives the run's CPU,
//! process count and peak commit. Meanwhile a sampler thread counts other jobs' processes, and `GetSystemTimes` at both
//! ends gives the load the rest of the machine added.

use crate::state;
use std::fs::File;
use std::os::windows::io::AsRawHandle;
use std::os::windows::process::CommandExt;
use std::path::{Path, PathBuf};
use std::process::{Command, Stdio};
use std::sync::mpsc;
use std::time::{Duration, Instant};
use windows_sys::Win32::Foundation::{CloseHandle, HANDLE, INVALID_HANDLE_VALUE};
use windows_sys::Win32::System::Diagnostics::ToolHelp::{
    CreateToolhelp32Snapshot, PROCESSENTRY32W, Process32FirstW, Process32NextW, TH32CS_SNAPPROCESS, TH32CS_SNAPTHREAD,
    THREADENTRY32, Thread32First, Thread32Next,

use windows_sys::Win32::System::JobObjects::{
    AssignProcessToJobObject, CreateJobObjectW, JOB_OBJECT_LIMIT_AFFINITY, JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE,
    JOB_OBJECT_LIMIT_PRIORITY_CLASS, JOBOBJECT_BASIC_ACCOUNTING_INFORMATION, JOBOBJECT_EXTENDED_LIMIT_INFORMATION,
    JobObjectBasicAccountingInformation, JobObjectExtendedLimitInformation, QueryInformationJobObject,
    SetInformationJobObject,
};
use windows_sys::Win32::System::Threading::{

/// Where a run's output goes: one file for both streams through one handle (as `> log.txt 2>&1`), or two files.
pub enum Output {
    Both(PathBuf),
    Split(PathBuf, PathBuf),
}

#[derive(Clone, Copy, PartialEq, Debug)]
pub enum Priority {
    BelowNormal,
    /// For GPU-feeding jobs, which starve at BelowNormal (LONG_RUNS.md).
    Normal,
}

impl Priority {
    pub fn parse(s: &str) -> Result<Priority, String> {
        match s.to_ascii_lowercase().as_str() {
            "belownormal" => Ok(Priority::BelowNormal),
            "normal" => Ok(Priority::Normal),
            _ => Err(format!("unknown priority {s} (BelowNormal or Normal)")),
        }
    }

    fn class(self) -> u32 {
        match self {
            Priority::BelowNormal => BELOW_NORMAL_PRIORITY_CLASS,
            Priority::Normal => NORMAL_PRIORITY_CLASS,
        }
    }
}

pub struct RunSpec {
    /// A path with a directory part is made absolute against `runs`'s own working directory; a bare name is searched on PATH.
    pub exe: PathBuf,
    pub args: Vec<String>,
    /// `(VAR, value)` set for the run; an empty value removes VAR (as `cpu_ab.ps1`'s old arm unset its variable).
    pub env: Vec<(String, String)>,
    pub cwd: Option<PathBuf>,
    pub output: Output,
    pub priority: Priority,
    pub affinity: usize,
    /// How long to wait, after the main process exits, for the rest of the job to exit.
    pub straggler_wait: Duration,
    /// Other jobs' process name patterns (`matches`).
    pub others: Vec<String>,
}

impl RunSpec {
    pub fn new(exe: impl Into<PathBuf>, args: Vec<String>, output: Output) -> RunSpec {
        RunSpec {
            exe: exe.into(),
            args,
            env: Vec::new(),
            cwd: None,

/// Other sessions' jobs (`quiet_ab`'s list): self-play training and the League client.

#[derive(Debug, Clone)]
pub struct RunResult {
    pub exit: i32,
    /// Seconds from the start to the main process's exit.
    pub wall: f64,
    /// User plus kernel seconds of every process the job held (the split is unreliable here, LONG_RUNS.md).
    pub job_cpu: f64,
    pub procs: u32,
    /// Processes still running when the straggler wait ran out; closing the job killed them.
    pub stragglers: u32,
    pub peak_proc_mb: f64,
    pub peak_job_mb: f64,
    /// Other processes' share of the machine during the run (`other_pct`).
    pub other_pct: f64,
    /// The most other jobs' processes seen at once.
    pub others: u32,

struct Handle(HANDLE);

impl Drop for Handle {
    fn drop(&mut self) {
        unsafe { CloseHandle(self.0) };
    }
}

/// A job object with the run's limits; closing it kills whatever is still in it.
struct Job(Handle);

impl Job {
    fn new(priority: Priority, affinity: usize) -> Result<Job, String> {
        let h = unsafe { CreateJobObjectW(std::ptr::null(), std::ptr::null()) };
        if h.is_null() {
            return Err(last_error("CreateJobObjectW"));
        }
        let job = Job(Handle(h));
        let mut info: JOBOBJECT_EXTENDED_LIMIT_INFORMATION = unsafe { std::mem::zeroed() };
        info.BasicLimitInformation.LimitFlags = JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE | JOB_OBJECT_LIMIT_AFFINITY | JOB_OBJECT_LIMIT_PRIORITY_CLASS;
        info.BasicLimitInformation.Affinity = affinity;
        info.BasicLimitInformation.PriorityClass = priority.class();
        let ok = unsafe { SetInformationJobObject(h, JobObjectExtendedLimitInformation, (&raw const info).cast(), size_of_val(&info) as u32) };
        if ok == 0 {
            return Err(last_error("SetInformationJobObject"));
        }
        Ok(job)
    }

    fn basic(&self) -> JOBOBJECT_BASIC_ACCOUNTING_INFORMATION {
        let mut b: JOBOBJECT_BASIC_ACCOUNTING_INFORMATION = unsafe { std::mem::zeroed() };
        unsafe { QueryInformationJobObject(self.0.0, JobObjectBasicAccountingInformation, (&raw mut b).cast(), size_of_val(&b) as u32, std::ptr::null_mut()) };
        b
    }

    fn extended(&self) -> JOBOBJECT_EXTENDED_LIMIT_INFORMATION {
        let mut e: JOBOBJECT_EXTENDED_LIMIT_INFORMATION = unsafe { std::mem::zeroed() };
        unsafe { QueryInformationJobObject(self.0.0, JobObjectExtendedLimitInformation, (&raw mut e).cast(), size_of_val(&e) as u32, std::ptr::null_mut()) };
        e
    }
}

fn last_error(what: &str) -> String {
    format!("{what} failed: {}", std::io::Error::last_os_error())
}

fn create(p: &Path) -> Result<File, String> {
    File::create(p).map_err(|e| format!("{}: {e}", p.display()))
}

/// A relative path with a directory part, made absolute against this process's directory: with the child's
/// `current_dir` set, Rust leaves it unspecified which directory a relative program path is resolved against
/// (`pin.ps1` had this bug, RELATED_WORK §66). A bare name is left for the PATH search.
fn resolve_exe(exe: &Path) -> Result<PathBuf, String> {
    if exe.components().count() > 1 {
        std::path::absolute(exe).map_err(|e| format!("{}: {e}", exe.display()))
    } else {
        Ok(exe.to_path_buf())
    }
}

/// Resumes every thread of `pid` (a process started suspended has one).
fn resume(pid: u32) -> Result<(), String> {
    let snap = unsafe { CreateToolhelp32Snapshot(TH32CS_SNAPTHREAD, 0) };
    if snap == INVALID_HANDLE_VALUE {
        return Err(last_error("CreateToolhelp32Snapshot"));
    }
    let snap = Handle(snap);
    let mut e: THREADENTRY32 = unsafe { std::mem::zeroed() };
    e.dwSize = size_of::<THREADENTRY32>() as u32;
    let mut resumed = 0;
    let mut more = unsafe { Thread32First(snap.0, &mut e) };
    while more != 0 {
        if e.th32OwnerProcessID == pid {
            let t = unsafe { OpenThread(THREAD_SUSPEND_RESUME, 0, e.th32ThreadID) };
            if t.is_null() {
                return Err(last_error("OpenThread"));
            }
            let t = Handle(t);
            if unsafe { ResumeThread(t.0) } == u32::MAX {
                return Err(last_error("ResumeThread"));
            }
            resumed += 1;
        }
        more = unsafe { Thread32Next(snap.0, &mut e) };
    }
    if resumed == 0 { Err(format!("no thread of process {pid} to resume")) } else { Ok(()) }
}

/// Every running process: (pid, name in lower case without `.exe`).
pub fn processes() -> Vec<(u32, String)> {
    let mut out = Vec::new();
    let snap = unsafe { CreateToolhelp32Snapshot(TH32CS_SNAPPROCESS, 0) };
    if snap == INVALID_HANDLE_VALUE {
        return out;
    }
    let snap = Handle(snap);
    let mut e: PROCESSENTRY32W = unsafe { std::mem::zeroed() };
    e.dwSize = size_of::<PROCESSENTRY32W>() as u32;
    let mut more = unsafe { Process32FirstW(snap.0, &mut e) };
    while more != 0 {
        let n = e.szExeFile.iter().position(|&c| c == 0).unwrap_or(e.szExeFile.len());
        let name = String::from_utf16_lossy(&e.szExeFile[..n]).to_lowercase();
        out.push((e.th32ProcessID, name.strip_suffix(".exe").unwrap_or(&name).to_string()));
        more = unsafe { Process32NextW(snap.0, &mut e) };
    }
    out
}

/// Whether process `name` matches `pattern`, as PowerShell's `-like` on `ProcessName` did: `*` matches any run of
/// characters, case is ignored, and the name's `.exe` is dropped.
pub fn matches(pattern: &str, name: &str) -> bool {
    fn go(p: &[u8], n: &[u8]) -> bool {
        match p.split_first() {
            None => n.is_empty(),
            Some((b'*', rest)) => (0..=n.len()).any(|i| go(rest, &n[i..])),
            Some((c, rest)) => n.first() == Some(c) && go(rest, &n[1..]),
        }
    }
    let name = name.to_lowercase();
    go(pattern.to_lowercase().as_bytes(), name.strip_suffix(".exe").unwrap_or(&name).as_bytes())
}

pub fn count_others(patterns: &[String]) -> u32 {
    processes().iter().filter(|(_, n)| patterns.iter().any(|p| matches(p, n))).count() as u32
}

/// Other processes' share of the machine in percent: its busy time less the job's CPU, over its total processor time
/// (wall × logical processors), the subtraction `clean.py` did. `GetSystemTimes`'s busy time includes interrupt and
/// DPC time no job is charged, so this reads slightly high, as `clean.py`'s `% Processor Time` did.
pub fn other_pct(busy: f64, total: f64, job_cpu: f64) -> f64 {
    if total <= 0.0 { 0.0 } else { (100.0 * (busy - job_cpu) / total).max(0.0) }
}

/// `quiet_ab`'s cleaning rule: a run counts when it succeeded, other processes stayed under `foreign_max`% of the
/// machine, and no other job's process appeared.
pub fn clean(exit: i32, other_pct: f64, others: u32, foreign_max: f64) -> bool {
    exit == 0 && others == 0 && other_pct < foreign_max
}

pub fn run(spec: &RunSpec) -> Result<RunResult, String> {
    let exe = resolve_exe(&spec.exe)?;
    let mut cmd = Command::new(&exe);
    cmd.args(&spec.args).stdin(Stdio::null()).creation_flags(CREATE_SUSPENDED);
    for (k, v) in &spec.env {
        if v.is_empty() {
            cmd.env_remove(k);
        } else {
            cmd.env(k, v);
        }
    }
    if let Some(d) = &spec.cwd {
        cmd.current_dir(d);
    }
    match &spec.output {
        Output::Both(p) => {
            let f = create(p)?;
            cmd.stderr(f.try_clone().map_err(|e| format!("{}: {e}", p.display()))?).stdout(f);
        }
        Output::Split(o, e) => {
            cmd.stdout(create(o)?).stderr(create(e)?);
        }
    }
    let job = Job::new(spec.priority, spec.affinity)?;
    // The sampler ends when `stop` is dropped, on every return path.
    let (stop, stopped) = mpsc::channel::<()>();
    let patterns = spec.others.clone();
    let sampler = std::thread::spawn(move || {
        let mut most = count_others(&patterns);
        while let Err(mpsc::RecvTimeoutError::Timeout) = stopped.recv_timeout(Duration::from_secs(2)) {
            most = most.max(count_others(&patterns));
        }
        most.max(count_others(&patterns))
    });
    let t0 = state::times();
    let start = Instant::now();
    let mut child = cmd.spawn().map_err(|e| format!("starting {}: {e}", exe.display()))?;
    if unsafe { AssignProcessToJobObject(job.0.0, child.as_raw_handle() as HANDLE) } == 0 {
        // for example a parent job whose affinity limit rejects ours: a run outside the job would count only itself
        let err = last_error("AssignProcessToJobObject");
        let _ = child.kill();
        let _ = child.wait();
        return Err(format!("{err}; the run was not started"));
    }
    if let Err(e) = resume(child.id()) {
        let _ = child.kill();
        let _ = child.wait();
        return Err(e);
    }
    let status = child.wait().map_err(|e| format!("waiting for {}: {e}", exe.display()))?;
    let wall = start.elapsed().as_secs_f64();
    // the job counts until its last process exits (sweep_job.ps1's note)
    let deadline = Instant::now() + spec.straggler_wait;
    let mut basic = job.basic();
    while basic.ActiveProcesses > 0 && Instant::now() < deadline {
        std::thread::sleep(Duration::from_millis(50));
        basic = job.basic();
    }
    let ext = job.extended();
    let t1 = state::times();
    drop(stop);
    let others = sampler.join().unwrap_or(0);
```

```rust
#[cfg(test)]
```

```rust
fn main() {

        Ok(code) => code,
        Err(e) => {
            eprintln!("runs: {e}\n{USAGE}");
            2
        }
    };
    std::process::exit(code);

fn dispatch(args: &[String]) -> Result<i32, String> {
    let (cmd, rest) = args.split_first().ok_or("no command")?;
    match cmd.as_str() {
        "dir" => {
            println!("{}", run_dir()?.display());
            Ok(0)
        }
        "state" => {
            println!("{}", state::line());
            Ok(0)
        }
        "run" => cmd_run(rest),
        _ => Err(format!("unknown command {cmd}")),
    }
}

/// `runs run`: one measured run; exits with its exit code, as `pin.ps1` did.
fn cmd_run(words: &[String]) -> Result<i32, String> {
    let p = parse(words);
    p.check(&["affinity", "priority"])?;
    let [dir] = &p.pos[..] else { return Err("run takes one directory".into()) };
    let (env, cmd) = split_env(&p.rest);
    let (exe, args) = cmd.split_first().ok_or("run needs an exe after --")?;
    let dir = PathBuf::from(dir);
    std::fs::create_dir_all(&dir).map_err(|e| format!("{}: {e}", dir.display()))?;
    let mut spec = job::RunSpec::new(exe, args.to_vec(), job::Output::Split(dir.join("out.txt"), dir.join("err.txt")));
    spec.env = env;
    apply_limits(&mut spec, &p)?;
    let rtp = state::rtp();
    let r = job::run(&spec)?;
    let label = dir.file_name().map_or("run".to_string(), |n| n.to_string_lossy().into_owned());
    println!("{}", result_line(&label, &r, rtp));
    Ok(r.exit)
}

/// `--affinity` and `--priority`, where given.
fn apply_limits(spec: &mut job::RunSpec, p: &Parsed) -> Result<(), String> {
    if let Some(m) = p.one("affinity")? {
        spec.affinity = parse_mask(m)?;
    }
    if let Some(v) = p.one("priority")? {
        spec.priority = job::Priority::parse(v)?;
    }
    Ok(())
}

/// The one line per run that `run` prints and `time` logs, with units as `sweep_job.ps1` wrote them.
fn result_line(label: &str, r: &job::RunResult, rtp: Option<bool>) -> String {
    format!(
        "{label} wall={:.1}s jobcpu={:.2}s procs={} stragglers={} peakproc={:.0}MB peakjob={:.0}MB other={:.0}% others={} rtp={} exit={}",
        r.wall,
        r.job_cpu,
        r.procs,
        r.stragglers,
        r.peak_proc_mb,
        r.peak_job_mb,
        r.other_pct,
        r.others,
        state::rtp_text(rtp),
        r.exit
    )
}

/// Command-line words as `runs` reads them: positional words, then `--name [value]...` options (an option takes the
/// words up to the next `--name`), then, after a bare `--`, the rest as given.
#[derive(Debug)]
struct Parsed {
    pos: Vec<String>,
    opts: Vec<(String, Vec<String>)>,
    rest: Vec<String>,
}

fn parse(words: &[String]) -> Parsed {
    let mut p = Parsed { pos: vec![], opts: vec![], rest: vec![] };
    for (i, w) in words.iter().enumerate() {
        if w == "--" {
            p.rest = words[i + 1..].to_vec();
            break;
        }
        if let Some(name) = w.strip_prefix("--") {
            p.opts.push((name.to_string(), vec![]));
        } else if let Some((_, values)) = p.opts.last_mut() {
            values.push(w.clone());
        } else {
            p.pos.push(w.clone());
        }
    }
    p
}

impl Parsed {
    /// An error for an option not in `known`.
    fn check(&self, known: &[&str]) -> Result<(), String> {
        match self.opts.iter().find(|(n, _)| !known.contains(&n.as_str())) {
            Some((n, _)) => Err(format!("unknown option --{n}")),
            None => Ok(()),
        }
    }

    /// Every occurrence's values of a repeatable option.
    fn all(&self, name: &str) -> Vec<&[String]> {
        self.opts.iter().filter(|(n, _)| n == name).map(|(_, v)| &v[..]).collect()
    }

    /// The value of a one-value option, if given (the last occurrence wins).
    fn one(&self, name: &str) -> Result<Option<&str>, String> {
        match self.all(name).last() {
            None => Ok(None),
            Some([v]) => Ok(Some(v)),
            Some(_) => Err(format!("--{name} takes one value")),
        }
    }

    /// Whether a switch with no value was given.
    fn flag(&self, name: &str) -> Result<bool, String> {
        match self.all(name).last() {
            None => Ok(false),
            Some([]) => Ok(true),
            Some(_) => Err(format!("--{name} takes no value")),
        }
    }
}

/// Whether `w` is `VAR=value` with VAR matching `[A-Za-z_][A-Za-z0-9_]*`.
fn is_env(w: &str) -> bool {
    let Some((k, _)) = w.split_once('=') else { return false };
    let mut c = k.chars();
    c.next().is_some_and(|f| f == '_' || f.is_ascii_alphabetic()) && c.all(|x| x == '_' || x.is_ascii_alphanumeric())
}

/// The leading `VAR=value` words as environment, and the rest: the exe and its arguments.
fn split_env(words: &[String]) -> (Vec<(String, String)>, &[String]) {
    let n = words.iter().take_while(|w| is_env(w)).count();
    let env = words[..n].iter().map(|w| w.split_once('=').map(|(k, v)| (k.to_string(), v.to_string())).unwrap()).collect();
    (env, &words[n..])
}

/// An affinity mask in hex, as `start /affinity` takes it (`FFF`, or `0xFFF`).
fn parse_mask(s: &str) -> Result<usize, String> {
    let hex = s.strip_prefix("0x").or_else(|| s.strip_prefix("0X")).unwrap_or(s);
    usize::from_str_radix(hex, 16).map_err(|_| format!("bad affinity mask {s} (hex, as FFF)"))
}

/// The checkout this exe was built in: the nearest folder above it holding `tools/runs/Cargo.toml` (four levels for
/// `target/release/runs.exe`, five for a test exe in `target/debug/deps`). `kk.sh` follows its own script's checkout
/// the same way, so a tool built in a worktree writes to that worktree's run directory wherever it is called from.
fn checkout() -> Result<PathBuf, String> {
    let exe = std::env::current_exe().map_err(|e| e.to_string())?;
    exe.ancestors()
        .find(|a| a.join(r"tools\runs\Cargo.toml").is_file())
        .map(Path::to_path_buf)
        .ok_or_else(|| format!("{} is not inside a checkout's tools/runs", exe.display()))
}

/// This checkout's run directory, `%TEMP%\tatic-runs\<checkout folder>`, created (`kk.sh`'s rule).
fn run_dir() -> Result<PathBuf, String> {
    let c = checkout()?;
    let d = long_path(&std::env::temp_dir()).join("tatic-runs").join(c.file_name().ok_or("the checkout has no folder name")?);
    std::fs::create_dir_all(&d).map_err(|e| format!("{}: {e}", d.display()))?;
    Ok(d)
}

/// `p` with 8.3 short names expanded (`%TEMP%` can be `C:\Users\WINSTO~1\...`); `p` itself if that fails.
fn long_path(p: &Path) -> PathBuf {
    let w: Vec<u16> = p.as_os_str().encode_wide().chain([0]).collect();
    let mut buf = vec![0u16; 32768];
    let n = unsafe { windows_sys::Win32::Storage::FileSystem::GetLongPathNameW(w.as_ptr(), buf.as_mut_ptr(), buf.len() as u32) } as usize;
    if n == 0 || n >= buf.len() { p.to_path_buf() } else { PathBuf::from(OsString::from_wide(&buf[..n])) }
}
```

```rust
//! `runs cmp <tag>`: compares `<tag>_old_<s>` with `<tag>_new_<s>` (salts 1 and 2) under the run directory, with
//! timings and libtest's harness lines normalized away; a difference that sorting both files removes is reported as
//! "(order only)". Ported line for line from `gate_cmp.py`, its regular expressions kept in byte mode (`(?-u)`), with

use regex::bytes::{NoExpand, Regex};
use std::path::Path;

/// The 1-based tab-separated field dropped from each stage file (its seconds).
const CUT: [(&str, usize); 6] = [("cold.tsv", 7), ("own.tsv", 7), ("pooled.tsv", 7), ("mines.tsv", 2), ("pooled_prefs.tsv", 2), ("m.tsv", 5)];

struct Norm {
    time: Regex,
    drop: Regex,
    filtered: Regex,
    run: Regex,
}

impl Norm {
    fn new(tag: &str) -> Norm {
        Norm {
            time: Regex::new(r"(?-u)[0-9]+(\.[0-9]+)?(s|ms|\xC2\xB5s)\b").unwrap(),
            drop: Regex::new(r"(?-u)^(running [0-9]+ tests?|test .* \.\.\. (ok|FAILED|ignored)|test result: .*|)$").unwrap(),
            filtered: Regex::new(r"(?-u)[0-9]+ filtered out").unwrap(),
            run: Regex::new(&format!(r"(?-u){}_(old|new)", regex::escape(tag))).unwrap(),
        }
    }

    /// A file's lines, normalized by its name.
    fn file(&self, path: &Path) -> std::io::Result<Vec<Vec<u8>>> {
        let data = std::fs::read(path)?;
        let name = path.file_name().map(|n| n.to_string_lossy().into_owned()).unwrap_or_default();
        let mut lines: Vec<&[u8]> = data.split(|&b| b == b'\n').collect();
        if lines.last().is_some_and(|l| l.is_empty()) {
            lines.pop();
        }
        if let Some(&(_, field)) = CUT.iter().find(|(n, _)| *n == name) {
            // as `cut`: a line with no tab is kept whole
            return Ok(lines
                .iter()
                .map(|l| {
                    if l.contains(&b'\t') {
                        l.split(|&b| b == b'\t').enumerate().filter(|&(i, _)| i != field - 1).map(|(_, p)| p).collect::<Vec<_>>().join(&b'\t')
                    } else {
                        l.to_vec()
                    }
                })
                .collect());
        }
        if name.ends_with(".txt") || name.ends_with(".log") {
            return Ok(lines
                .iter()
                .filter_map(|l| {
                    let l = self.time.replace_all(l, NoExpand(b"T"));
                    let l = self.run.replace_all(&l, NoExpand(b"RUN"));
                    let l = self.filtered.replacen(&l, 1, NoExpand(b"N filtered out"));
                    (!self.drop.is_match(&l)).then(|| l.into_owned())
                })
                .collect());
        }
        Ok(lines.iter().map(|l| l.to_vec()).collect())
    }
}

/// Every file under `d`, as sorted `./`-relative paths with `/`; an error if `d` itself cannot be listed (`os.walk`
/// skipped unreadable subdirectories, and so does this).
fn files(d: &Path) -> std::io::Result<Vec<String>> {
    let mut out = Vec::new();
    let mut stack = vec![d.to_path_buf()];
    let mut top = true;
    while let Some(dir) = stack.pop() {
        let entries = match std::fs::read_dir(&dir) {
            Ok(e) => e,
            Err(e) if top => return Err(e),
            Err(_) => continue,
        };
        top = false;
        for e in entries.flatten() {
            let p = e.path();
            if p.is_dir() {
                stack.push(p);
            } else {
                out.push(format!("./{}", p.strip_prefix(d).unwrap().to_string_lossy().replace('\\', "/")));
            }
        }
    }
    out.sort();
    Ok(out)
}

/// `gate_cmp.py`'s output for `tag` under `dir`, one entry per line.
pub fn cmp(dir: &Path, tag: &str) -> Vec<String> {
    let norm = Norm::new(tag);
    let mut out = Vec::new();
    for s in 1..=2 {
        let (o, n) = (dir.join(format!("{tag}_old_{s}")), dir.join(format!("{tag}_new_{s}")));
        let (lo, ln) = match (files(&o), files(&n)) {
            (Ok(lo), Ok(ln)) => (lo, ln),
            (Err(e), _) | (_, Err(e)) => {
                out.push(format!("ERROR salt {s}: listing failed ({e})"));
                continue;
            }
        };
        if lo == ln {
            out.push(format!("salt {s}: same file list ({} files)", lo.len()));
        } else {
            out.extend(lo.iter().filter(|f| !ln.contains(f)).map(|f| format!("< {f}")));
            out.extend(ln.iter().filter(|f| !lo.contains(f)).map(|f| format!("> {f}")));
        }
        for f in &lo {
            let (a, b) = match (norm.file(&o.join(&f[2..])), norm.file(&n.join(&f[2..]))) {
                (Ok(a), Ok(b)) => (a, b),
                (Err(e), _) | (_, Err(e)) => {
                    out.push(format!("ERROR salt {s}: normalizing {f} failed ({e})"));
                    continue;
                }
            };
            if a == b {
                continue;
            }
            let (mut sa, mut sb) = (a, b);
            sa.sort();
            sb.sort();
            out.push(if sa == sb { format!("DIFF salt {s} {f} (order only)") } else { format!("DIFF salt {s} {f}") });
        }
    }
    out.push("cmp done".into());
    out
}

/// Whether `cmp`'s lines say the sides are the same: nothing but `salt <s>: same file list (..)` and `cmp done`. So
/// `DIFF`, `(order only)`, `ERROR`, `< f` and `> f` all count as a difference.
pub fn same(lines: &[String]) -> bool {
    lines.iter().all(|l| l == "cmp done" || (l.starts_with("salt ") && l.contains(": same file list (")))
}
```

```rust
//! `runs gate <tag> <old exe> <new exe>`: four sweeps in `hc_seq.sh`'s order (new 1, old 1, old 2, new 2), each in a
//! job (`runs::job`), into `<run dir>/<tag>_<arm>_<salt>`, then `runs cmp`. Progress goes to stdout and to
//! `<run dir>/<tag>_gate.txt`, which ends with `<tag> ALL` (the verdict, `<tag> cmp same|differs`, on the line before)
//! or `<tag> FAILED <why>`, so a background gate can be watched for it.

use crate::{append, cmp, job};
use std::path::Path;

/// A sweep's arguments to the church_bv exe.
pub fn sweep_args() -> Vec<String> {
    ["driver::sweep", "--exact", "--ignored", "--nocapture"].map(String::from).to_vec()
}

/// Runs the gate under `dir`; Ok(true) when every sweep succeeded and `cmp` found the sides the same.
pub fn gate(dir: &Path, tag: &str, old: &Path, new: &Path) -> Result<bool, String> {
    let log = dir.join(format!("{tag}_gate.txt"));
    let _ = std::fs::remove_file(&log);
    for arm in ["old", "new"] {
        for s in 1..=2 {
            let d = dir.join(format!("{tag}_{arm}_{s}"));
            if d.exists() {
                std::fs::remove_dir_all(&d).map_err(|e| format!("{}: {e}", d.display()))?;
            }
        }
    }
    let say = |line: String| -> Result<(), String> {
        println!("{line}");
        append(&log, &line)
    };
    for (arm, exe, s) in [("new", new, 1), ("old", old, 1), ("old", old, 2), ("new", new, 2)] {
        let out = dir.join(format!("{tag}_{arm}_{s}"));
        std::fs::create_dir_all(&out).map_err(|e| format!("{}: {e}", out.display()))?;
        let mut spec = job::RunSpec::new(exe, sweep_args(), job::Output::Both(out.join("log.txt")));
        spec.env = [("MACHINE_STATE", "0".to_string()), ("SWEEP_OUT", out.display().to_string()), ("SALT", s.to_string()), ("SWEEP", "mines own cold pooled".to_string())]
            .map(|(k, v)| (k.to_string(), v))
            .to_vec();
        match job::run(&spec) {
            Ok(r) if r.exit == 0 => say(format!("{tag} {arm} {s} {:.0}s cpu={:.1}", r.wall, r.job_cpu))?,
            Ok(r) => {
                say(format!("{tag} FAILED {arm} {s} exit={} (see {})", r.exit, out.join("log.txt").display()))?;
                return Ok(false);
            }
            Err(e) => {
                say(format!("{tag} FAILED {arm} {s}: {e}"))?;
                return Ok(false);
            }
        }
    }
    let lines = cmp::cmp(dir, tag);
    for l in &lines {
        println!("{l}");
    }
    let cmp_txt = dir.join(format!("{tag}_cmp.txt"));
    std::fs::write(&cmp_txt, lines.join("\n") + "\n").map_err(|e| format!("{}: {e}", cmp_txt.display()))?;
    let same = cmp::same(&lines);
    say(format!("{tag} cmp {}", if same { "same" } else { "differs" }))?;
    say(format!("{tag} ALL"))?;
    Ok(same)
}
```

```rust
//! `runs time`: alternating timing of two or more arms in rounds, each run measured by `runs::job`. Before each round
//! it waits for a quiet machine, and it counts only rounds no one else loaded: `scripts/quiet_ab`'s rules, which it
//! replaced, with `cpu_ab.ps1`'s, `cpu_arms.ps1`'s and `hc_rounds.ps1`'s experiments as presets.

use regex::Regex;
use std::fmt::Write as _;
use std::path::{Path, PathBuf};
use std::time::{Duration, Instant, SystemTime, UNIX_EPOCH};

#[derive(Clone, Debug, PartialEq)]
pub struct Arm {
    pub name: String,
    pub env: Vec<(String, String)>,
    pub exe: String,
    pub args: Vec<String>,
}

/// `--grep NAME=REGEX`: the first capture group of the last output line REGEX matches becomes column NAME.
pub struct Grep {
    pub name: String,
    pub re: Regex,
}

pub struct Timing {
    pub dir: PathBuf,
    pub rounds: usize,
    pub max_hours: f64,
    pub others: Vec<String>,
    pub foreign_max: f64,

    pub keep_dirty: bool,

    pub greps: Vec<Grep>,
    pub affinity: usize,
    pub priority: job::Priority,
    pub arms: Vec<Arm>,
}

/// One arm from its words: `<name> [VAR=val]... <exe> <args>...`.
pub fn parse_arm(words: &[String]) -> Result<Arm, String> {
    let (name, rest) = words.split_first().ok_or("an empty arm")?;
    let (env, cmd) = crate::split_env(rest);
    let (exe, args) = cmd.split_first().ok_or_else(|| format!("arm {name} has no exe"))?;
    Ok(Arm { name: name.clone(), env, exe: exe.clone(), args: args.to_vec() })
}

pub fn parse_grep(s: &str) -> Result<Grep, String> {
    let (name, re) = s.split_once('=').ok_or_else(|| format!("--grep {s}: expected NAME=REGEX"))?;
    let re = Regex::new(re).map_err(|e| format!("--grep {name}: {e}"))?;
    if re.captures_len() < 2 {
        return Err(format!("--grep {name}: the regex needs a capture group"));
    }
    Ok(Grep { name: name.to_string(), re })
}

/// The first capture of the last line of `text` that `re` matches (`cpu_ab.ps1` took the first line; it matters only
/// if a line repeats). `lines` drops a CR before each LF.
pub fn grep_last(re: &Regex, text: &str) -> Option<String> {
    text.lines().rev().find_map(|l| re.captures(l)).and_then(|c| c.get(1)).map(|m| m.as_str().to_string())
}

/// The arms' order in round `r` (from 1): rotated left by r - 1, so two arms go AB, BA, AB, ... as `ab.sh` and
/// `hc_rounds.ps1` did, and more arms rotate as `cpu_arms.ps1` did.
pub fn order(arms: usize, r: usize) -> Vec<usize> {
    (0..arms).map(|i| (i + r - 1) % arms).collect()
}

/// `s` with `{r}`, `{arm}` and `{dir}` replaced.
pub fn subst(s: &str, r: usize, arm: &str, dir: &Path) -> String {
    s.replace("{r}", &r.to_string()).replace("{arm}", arm).replace("{dir}", &dir.display().to_string())
}

/// `--sweep`: `hc_rounds.ps1`'s experiment, full salt-1 sweeps on normal pages, with the sweep's machine-state checks
/// moved out of the job (`runs` records the machine itself).
pub fn sweep_arms(old: &str, new: &str) -> Vec<Arm> {
    let env: Vec<(String, String)> = [("MACHINE_STATE", "0"), ("SALT", "1"), ("SWEEP", "mines own cold pooled"), ("MIMALLOC_ALLOW_LARGE_OS_PAGES", "0"), ("SWEEP_OUT", "{dir}/{arm}.{r}")]
        .map(|(k, v)| (k.to_string(), v.to_string()))
        .to_vec();
    [("old", old), ("new", new)].map(|(name, exe)| Arm { name: name.into(), env: env.clone(), exe: exe.into(), args: crate::gate::sweep_args() }).to_vec()
}

/// `--pcs`: `cpu_ab.ps1`'s and `cpu_arms.ps1`'s experiment, `proof_cost_split` on cmp3d with its own library
/// (`<scripts>/cmp3d_own_rules.txt`) and 300 laws. With one exe the arms come from `arm_envs` (`NAME:VAR=val,...`;
/// `NAME:` for none); with two exes they are `old` and `new`.
pub fn pcs_arms(scripts: &Path, exes: &[String], arm_envs: &[String]) -> Result<Vec<Arm>, String> {
    let base = vec![
        ("CHECK_FAMILY".to_string(), "cmp3d".to_string()),
        ("CHECK_RULES".to_string(), scripts.join("cmp3d_own_rules.txt").display().to_string()),
        ("RULEMINER_LAWS".to_string(), "300".to_string()),
    ];
    let args: Vec<String> = ["search::proof_cost_split", "--exact", "--ignored", "--nocapture"].map(String::from).to_vec();
    let arm = |name: &str, exe: &str, extra: Vec<(String, String)>| Arm { name: name.into(), env: [base.clone(), extra].concat(), exe: exe.into(), args: args.clone() };
    match (exes, arm_envs.is_empty()) {
        ([old, new], true) => Ok(vec![arm("old", old.as_str(), vec![]), arm("new", new.as_str(), vec![])]),
        ([exe], false) => arm_envs
            .iter()
            .map(|a| {
                let (name, vars) = a.split_once(':').ok_or_else(|| format!("--arm-env {a}: expected NAME:VAR=val,..."))?;
                let env = vars
                    .split(',')
                    .filter(|v| !v.is_empty())
                    .map(|v| v.split_once('=').map(|(k, x)| (k.to_string(), x.to_string())).ok_or_else(|| format!("--arm-env {a}: {v} is not VAR=val")))
                    .collect::<Result<Vec<_>, _>>()?;
                Ok(arm(name, exe.as_str(), env))
            })
            .collect(),
        _ => Err("--pcs takes <exe> with --arm-env options, or <old exe> <new exe> without".into()),
    }
}

/// `proof_cost_split`'s `COST rule-proofs: n=.. build=..ms check=..ms ...` line (search.rs), whose build and check

pub fn pcs_greps() -> Vec<Grep> {

fn tsv_header(greps: &[Grep]) -> String {
    let mut h = "arm\tround\tposition\tstart\twall_s\tjobcpu_s\tprocs\tstragglers\tpeakproc_mb\tpeakjob_mb\tother_pct\tothers\trtp\texit\tclean".to_string();
    for g in greps {
        h.push('\t');
        h.push_str(&g.name);
    }
    h
}

fn tsv_row(w: &Row) -> String {
    let r = &w.r;
    let mut s = format!(
        "{}\t{}\t{}\t{}\t{:.2}\t{:.3}\t{}\t{}\t{:.0}\t{:.0}\t{:.1}\t{}\t{}\t{}\t{}",

    for g in &w.greps {
        s.push('\t');
        s.push_str(g.as_deref().unwrap_or(""));
    }
    s
}

fn median(mut v: Vec<f64>) -> f64 {
    v.sort_by(f64::total_cmp);
    match v.len() {
        0 => f64::NAN,
        n if n % 2 == 1 => v[n / 2],
        n => (v[n / 2 - 1] + v[n / 2]) / 2.0,
    }
}

/// Per arm over `rounds`: median and best of job CPU, wall and each grep column. Then each arm against the first,
/// paired by round: the differences, their median, and how many rounds it won (lower wins).
fn summary(rows: &[Row], arms: &[String], greps: &[String], rounds: &[usize]) -> String {
    let names: Vec<String> = ["jobcpu".to_string(), "wall".to_string()].into_iter().chain(greps.iter().cloned()).collect();
    let value = |w: &Row, m: usize| -> Option<f64> {
        match m {
            0 => Some(w.r.job_cpu),
            1 => Some(w.r.wall),
            _ => w.greps.get(m - 2)?.as_deref()?.parse().ok(),
        }
    };
    let get = |arm: &str, r: usize, m: usize| rows.iter().find(|w| w.arm == arm && w.round == r).and_then(|w| value(w, m));
    let mut s = format!("{} rounds: {:?}\n", rounds.len(), rounds);
    for arm in arms {
        write!(s, "{arm}:").unwrap();
        for (m, name) in names.iter().enumerate() {
            let v: Vec<f64> = rounds.iter().filter_map(|&r| get(arm, r, m)).collect();
            let best = v.iter().copied().fold(f64::INFINITY, f64::min);
            write!(s, " {name} median={:.3} best={best:.3}", median(v)).unwrap();
        }
        s.push('\n');
    }
    if let Some((first, rest)) = arms.split_first() {
        for arm in rest {
            for (m, name) in names.iter().enumerate() {
                let d: Vec<(usize, f64)> = rounds.iter().filter_map(|&r| Some((r, get(arm, r, m)? - get(first, r, m)?))).collect();
                let wins = d.iter().filter(|(_, x)| *x < 0.0).count();
                let list: Vec<String> = d.iter().map(|(r, x)| format!("r{r} {x:+.3}")).collect();
                let med = median(d.iter().map(|x| x.1).collect());
                writeln!(s, "{arm} - {first} {name}: median {med:+.3}, won {wins}/{}: {}", d.len(), list.join(", ")).unwrap();
            }
        }
    }
    s
}

/// Waits until the last `quiet_secs` of 2 s samples all had the machine under `foreign_max`% busy and no others'
/// process: nothing of ours runs meanwhile, so all of the load is others'. Err(why) at the deadline or on `stop`.
fn wait_quiet(t: &Timing, deadline: Instant, stop: &Path) -> Result<(), String> {
    let check = || {
        if Instant::now() >= deadline {
            Err("deadline".to_string())
        } else if stop.exists() {
            Err("stop".to_string())
        } else {
            Ok(())
        }
    };
    check()?;
    let need = (t.quiet_secs / 2) as usize;
    let (mut good, mut prev) = (0, state::times());
    while good < need {
        std::thread::sleep(Duration::from_secs(2)); // one sample
        check()?;
        let now = state::times();
        let quiet = now.load_since(&prev) < t.foreign_max && job::count_others(&t.others) == 0;
        prev = now;
        good = if quiet { good + 1 } else { 0 };
    }
    Ok(())
}

fn log_state(dir: &Path, when: &str) -> Result<(), String> {
    let line = format!("{when}: {}", state::line());
    println!("{line}");
    append(&dir.join("state.txt"), &line)
}

/// Runs the timing; Ok holds the line also written to `<dir>/done.txt`: `done <clean rounds>/<rounds> <why it stopped>`.
pub fn time(t: &Timing) -> Result<String, String> {
    let dir = &t.dir;
    for (i, a) in t.arms.iter().enumerate() {
        if t.arms[..i].iter().any(|b| b.name == a.name) {
            return Err(format!("arm {} appears twice; arms need distinct names", a.name));
        }
    }
    let tsv = dir.join("runs.tsv");
    if tsv.exists() {
        return Err(format!("{} already holds runs.tsv; use a fresh directory", dir.display()));
    }
    std::fs::create_dir_all(dir).map_err(|e| format!("{}: {e}", dir.display()))?;
    let stop = dir.join("stop");
    let _ = std::fs::remove_file(&stop);
    let _ = std::fs::remove_file(dir.join("done.txt"));
    append(&tsv, &tsv_header(&t.greps))?;
    log_state(dir, "start")?;
    let deadline = Instant::now() + Duration::from_secs_f64(t.max_hours * 3600.0);
    let mut rows: Vec<Row> = Vec::new();
    let (mut round, mut clean_rounds) = (0, Vec::new());
    let mut rtp_seen: Option<Option<bool>> = None;
    let why = 'timing: loop {
        let counted = if t.keep_dirty { round } else { clean_rounds.len() };
        if counted >= t.rounds {
            break if t.keep_dirty { "all rounds".to_string() } else { "clean rounds".to_string() };
        }
        if !t.keep_dirty && round >= t.max_rounds {
            break format!("max-rounds {}", t.max_rounds);
        }
        if let Err(why) = wait_quiet(t, deadline, &stop) {
            break why;
        }
        round += 1;
        let rtp = state::rtp();
        if rtp_seen.is_some_and(|seen| seen != rtp) {
            println!("rtp changed to {}", state::rtp_text(rtp));
        }
        rtp_seen = Some(rtp);
        let mut all_clean = true;
        for (pos, &i) in order(t.arms.len(), round).iter().enumerate() {
            let a = &t.arms[i];
            let label = format!("{}.{round}", a.name);
            let out = dir.join(format!("{label}.out.txt"));
            let sub = |s: &str| subst(s, round, &a.name, dir);
            let mut spec = job::RunSpec::new(sub(&a.exe), a.args.iter().map(|x| sub(x)).collect(), job::Output::Split(out.clone(), dir.join(format!("{label}.err.txt"))));
            spec.env = a.env.iter().map(|(k, v)| (k.clone(), sub(v))).collect();
            spec.affinity = t.affinity;
            spec.priority = t.priority;
            spec.others = t.others.clone();
            let start = SystemTime::now().duration_since(UNIX_EPOCH).map_or(0, |d| d.as_secs());
            let r = match job::run(&spec) {
                Ok(r) => r,
                Err(e) => break 'timing format!("{label}: {e}"),
            };
            let text = String::from_utf8_lossy(&std::fs::read(&out).unwrap_or_default()).into_owned();
            let greps = t.greps.iter().map(|g| grep_last(&g.re, &text)).collect();
            let clean = job::clean(r.exit, r.other_pct, r.others, t.foreign_max);
            println!("{}", crate::result_line(&label, &r, rtp));
            let row = Row { arm: a.name.clone(), round, pos: pos + 1, start, r, rtp, clean, greps };
            append(&tsv, &tsv_row(&row))?;
            all_clean &= clean;
            let exit = row.r.exit;
            rows.push(row);
            if exit != 0 {
                // a failing run would only fail again
                break 'timing format!("{label} failed (exit {exit}); see {}", out.display());
            }
        }
        if all_clean {
            clean_rounds.push(round);
        }
        println!("round {round} done, clean rounds {}", clean_rounds.len());
    };
    log_state(dir, "end")?;
    let names: Vec<String> = t.arms.iter().map(|a| a.name.clone()).collect();
    let gnames: Vec<String> = t.greps.iter().map(|g| g.name.clone()).collect();
    let mut s = format!("clean {}", summary(&rows, &names, &gnames, &clean_rounds));
    if t.keep_dirty {
        let all: Vec<usize> = (1..=round).collect();
        s += &format!("all {}", summary(&rows, &names, &gnames, &all));
    }
    std::fs::write(dir.join("summary.txt"), &s).map_err(|e| format!("{}: {e}", dir.display()))?;
    print!("{s}");
    let done = format!("done {}/{round} {why}", clean_rounds.len());
    std::fs::write(dir.join("done.txt"), format!("{done}\n")).map_err(|e| format!("{}: {e}", dir.display()))?;
    println!("{done}");
    Ok(done)
}
```

```rust
/// `runs time`: exits 0 unless a run failed.
fn cmd_time(words: &[String]) -> Result<i32, String> {
    let p = parse(words);
    p.check(&["rounds", "max-hours", "others", "foreign-max", "quiet-secs", "keep-dirty", "max-rounds", "grep", "affinity", "priority", "sweep", "pcs", "arm-env"])?;
    let [dir] = &p.pos[..] else { return Err("time takes one directory".into()) };
    let num = |name: &str, default: f64| -> Result<f64, String> {
        p.one(name)?.map_or(Ok(default), |v| v.parse().map_err(|_| format!("--{name} {v}: not a number")))
    };
    let mut greps = p.all("grep").iter().map(|v| match v {
        [g] => time::parse_grep(g),
        _ => Err("--grep takes one NAME=REGEX".to_string()),
    }).collect::<Result<Vec<_>, _>>()?;
    let arm_envs: Vec<String> = p.all("arm-env").iter().map(|v| v.join(" ")).collect();
    let (arms, default_rounds) = match (&p.all("sweep")[..], &p.all("pcs")[..]) {
        ([], []) => (p.rest.split(|w| w == "--").map(time::parse_arm).collect::<Result<Vec<_>, _>>()?, None),
        ([[old, new]], []) if p.rest.is_empty() => (time::sweep_arms(old, new), Some(6)),
        ([], [exes]) if p.rest.is_empty() => {
            greps.extend(time::pcs_greps());
            (time::pcs_arms(&checkout()?.join(r"docs\runs\2026-10-12\scripts"), exes, &arm_envs)?, None)
        }
        _ => return Err("give arms after --, or one of --sweep <old> <new> and --pcs <exe> [<new exe>]".into()),
    };
    let rounds = match (p.one("rounds")?, default_rounds) {
        (Some(v), _) => v.parse().map_err(|_| format!("--rounds {v}: not a number"))?,
        (None, Some(d)) => d,
        (None, None) => return Err("--rounds N is needed".into()),
    };
    let mut probe = job::RunSpec::new("", vec![], job::Output::Both(PathBuf::new()));
    apply_limits(&mut probe, &p)?;
    let t = time::Timing {
        dir: PathBuf::from(dir),
        rounds,
        max_hours: num("max-hours", 3.0)?,
        others: p.one("others")?.map_or_else(job::default_others, |v| v.split(',').map(String::from).collect()),
        foreign_max: num("foreign-max", 20.0)?,
        quiet_secs: num("quiet-secs", 60.0)? as u64,
        keep_dirty: p.flag("keep-dirty")?,
        max_rounds: p.one("max-rounds")?.map_or(Ok(4 * rounds), |v| v.parse().map_err(|_| format!("--max-rounds {v}: not a number")))?,
        greps,
        affinity: probe.affinity,
        priority: probe.priority,
        arms,
    };
    let done = time::time(&t)?;
    Ok(if done.contains(" failed") || done.contains(": starting ") { 1 } else { 0 })
}
```

```powershell
# sweep_xperf.ps1 <exe>: run from an elevated PowerShell. Records a kernel trace (sampled profile with stacks, context
# switches, all page faults, virtual allocations) over one salt-1 sweep run by `runs run` (children on normal pages, as
# driver::sweep sets; machine-state checks off, so the trace holds only the sweep), to find where the sweep's kernel time
# goes (docs/tier-cycle.md, "How often the large-page stall hits a sweep"). Needs tools/runs built
# (`cargo build --release --manifest-path tools/runs/Cargo.toml`). Writes <run dir>\sweep_xperf\trace.etl and the sweep's
# line to sweep.txt; analysing the trace with `xperf -i` needs no elevation. About a minute, plus the merge.
param([string]$exe)
$runs = Join-Path $PSScriptRoot '..\..\..\..\tools\runs\target\release\runs.exe'
$o = "$(& $runs dir)\sweep_xperf"
New-Item -ItemType Directory -Force $o | Out-Null
xperf -on PROC_THREAD+LOADER+PROFILE+CSWITCH+DISPATCHER+ALL_FAULTS+VIRT_ALLOC -stackwalk Profile -BufferSize 1024 -MinBuffers 512 -MaxBuffers 1024 -f "$o\kernel.etl"
if ($LASTEXITCODE) { throw "xperf -on failed ($LASTEXITCODE); is this PowerShell elevated?" }
try {

} finally {
    xperf -d "$o\trace.etl"
    Remove-Item "$o\kernel.etl" -EA 0
}
"trace: $o\trace.etl"
```
