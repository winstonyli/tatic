# Cleanup, trim and optimize (2026-10-26)

A break from v0.5 (`ROADMAP.md`) to trim unused code and docs and to speed up the gate. Four read-only surveys on
2026-10-26 (church_bv dead code; `src/`, `benches/`, top-level tests and `tools/`; docs and repo hygiene; throughput)
produced the items below. Each has a stable id; claims are the surveys' unless marked checked, and every item is
re-verified before it changes anything. `cargo check --all-targets` gave zero warnings on 2026-10-26, so no private
code is uncalled: what is dead is reachable only from retired families, ignored probes or tests.

Order chosen 2026-10-26: CU2, CU9, CU10, CU11 as one "streams era only" pass; then the CU1 spike; then CU14, CU15,
CU17; then CU3, CU5; then CU12, CU13. CU4, CU6, CU7, CU8, CU16 and CU18 get a second survey before any change.
Outcomes are recorded per item below as they land; leftovers go to `PARKED.md` when this plan closes.

## Correctness

- **CU1. Division by zero in proof witnesses.** `apply_prim_concrete` (`src/proof/tail.rs`) returns 0 for `div` and
  `mod` by zero and `assume_prim_fact` (`src/proof.rs`) postulates that result as an axiom, while `eval::apply_prim`
  returns `DivByZero` and the compiled Wasm traps (checked). Spike: whether a closed term that divides by zero passes
  `kernel_verify`; if so, decline on `Err` and share `eval`'s function (about 25 lines).
