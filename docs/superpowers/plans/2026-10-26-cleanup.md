## Correctness

- **CU1. Division by zero in proof witnesses.** `apply_prim_concrete` (`src/proof/tail.rs`) returns 0 for `div` and
  `mod` by zero and `assume_prim_fact` (`src/proof.rs`) postulates that result as an axiom, while `eval::apply_prim`
  returns `DivByZero` and the compiled Wasm traps (checked). Spike: whether a closed term that divides by zero passes
  `kernel_verify`; if so, decline on `Err` and share `eval`'s function (about 25 lines).
  **Spike 2026-10-26** (throwaway test, deleted): `div 7 0`, `mod 7 0`, `\x. div x 0` and `\x. x + div 7 0` are all
  kernel-verified and installed (`prove_closure_expr`, and `prove_pure_expr` above arity 0, both treat `div` as an
  opaque postulate; the instance prover postulates `div 7 0 = 0`); `if (div 7 0) 1 2` is not installed. No wrong
  value is reachable: the installed Wasm traps on every one, where the interpreter returns `DivByZero`, and nothing
  else folds a division. So the certificates hold in a total model (x/0 = 0, as in Lean), not in `eval`'s partial
  semantics; declining on `Err` in the instance prover alone would not change `kernel_verify` for any of these.
  **Re-spike 2026-10-27, after CU3** (throwaway test, deleted): `assume_prim_fact` is gone, so no postulate states
  x/0 = 0. All six terms (the four above, `if 7 / 0 then 1 else 2`, `\x. if x / 0 == 0 then 1 else 2`) pass
  `kernel_verify`, every one through `prove_closure_expr` (`div` an opaque postulate); arity 1 also through
  `prove_pure_expr`, arity 0 also through `prove_closure_expr_instance`. The total model survives only in
  `apply_prim_concrete`, inside `eval_concrete` (`src/proof/tail.rs`), which picks the instance prover's branches
  outside the kernel; the same prover's other concrete evaluator, `eval_concrete_dyn`, already defers to `eval::eval`
  and declines on `DivByZero`. `i64::MIN / -1` is not a second mismatch: `lower_wat` wraps it as `eval` does.
  **Done 2026-10-27** (option "one concrete evaluator"): `eval_concrete`, `apply_prim_concrete`,
  `dyn_frame_concrete_ints` and `src/proof/tail.rs` deleted; `classify_step` moved into `per_instance.rs` and every
  branch pick goes through `eval_concrete_dyn`. Test `an_instance_whose_branch_divides_by_zero_gets_no_proof` (a plain
  `If` and a tail-recursive loop's condition). `kernel_verify` is unchanged for the six spike terms
  (`prove_closure_expr` proves them); the README's "Division by zero is outside the theorems' claim" states what
  the certificates claim.
